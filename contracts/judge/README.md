# Judge

当前 E1 和 E2 使用 `e1-numbered-evidence-v3` 对完整公开对话评分。裁判评的是教师如何教学，学生的陈述和行动是证据。新版明确交还主动权的分档边界，为六维补充通用示例，并校验理由引用。预登记维度保持原样。历史 `e1-numbered-evidence-v2` 的结果与新版分档不可直接比较。机器规则和示例见 [schema](schema.mjs)。

本版使用评测身份 `evaluation-identity-v2` 和调用策略 `e1-call-policy-v4`。OpenRouter 裁判请求包含独立的 `reasoning.max_tokens`，总输出 `max_tokens` 同时覆盖推理和可见 JSON。出站字段和路由上报用量的回读步骤见[运行手册](../../docs/runbook.md)。

## 评分维度

| 维度 | 衡量什么 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- | --- |
| 误解修复 `misconception_repair` | 学生是否在理解错误原因后独立修正 | 未形成修复，或完整解抢先代替修复 | 只修复一部分，或学生复述教师的修正 | 教师指出原推理为何不成立，学生独立说出正确概念 |
| 增加与撤去支持 `support_escalation_and_fading` | 帮助随学生状态双向调整 | 支持强度固定 | 只有增加或撤去一个方向。开场完整解最高 1 分 | 学生受阻后增加支持，成功后持续撤去支持 |
| 交还主动权 `agency_handoff` | 推理和自我监控由谁主导 | 教师主导，学生没有自主推理步骤或实质检验。复述或仅察觉困惑后求助属于本档 | 教师仍主导方案，学生自主完成至少一个有限的推理步骤 | 学生在末三分之一主导实质推理或检验，例如自行选方法并解释其依据，或做一次检验并说明后果 |
| 保留有益试错 `productive_struggle` | 学生能否在适当支持下尝试解题 | 首个实质回应就给完整解或答案，后续克制不抵消 | 支持有反复，或后续过早代做 | 在关键卡点引导学生继续有效尝试，没有过早给完整解 |
| 表征转换 `representation_pivot` | 原讲法受阻后，换一种表征能否帮助学生理解 | 无机会、未转换或只换措辞。重讲开场完整解不计作转换 | 换了表征，学生尚未表现出理解 | 识别原讲法受阻，实质转换表征，学生表现出理解 |
| 验证或迁移 `verification_or_transfer` | 教师是否查证学生能独立解释或应用 | 无概念检查，或仅口头确认 | 尝试检查，但学生证据弱 | 学生能独立解释概念或迁移应用 |

六项等权，每项直接贡献 0–2 个原始分，六项都有效时 `total` 为它们的和，范围 0–12。每项占满分的 `1/6`，生产评分不重分配权重。旧 v6 的逐轮、轨迹聚合、任务义务、学生变化、完成乘子和 35/16/24/25 分层权重未接入当前总分。历史分数需要按原尺子读回。

`scored` 表示至少有一个通过校验的整数档。`validTotal` 要求六项均为通过校验的整数档。单项 `null` 表示未定档，不能计为 0。生产入口要求一次交齐六项，并在有限重试后把仍不合规或未定档的格子记为基础设施故障，产物为 `scored: false`、`validTotal: false`、`total: null`。失败尝试只供诊断。产物层支持部分分数语义，当前生产入口不发布这种部分结果。机器验收另见 [场景卡](../../docs/scenarios.md)。

## 证据绑定与观察窗口

- 现行视图是该格完整的公开对话。对话按原序编号，消息只给 `n`、`role` 和 `text`。学生画像、工具及私有状态不在视图内。旧 v6 的逐轮窗口设置不适用于这里。
- 裁判只返回含六个维度的 `results`。用当前视图的整数 `message_numbers` 或 `opportunity_numbers` 引用原件。本地用 `binding.messageIds[n-1]` 映射并校验哈希、范围、角色、顺序和重叠。每维理由解释分档，至少引用一个窗口内序号，格式为 `#N`。本地检查理由格式和序号范围，分档理由的语义仍由人回读核实。`judge.json` 的 `binding` 记录 run、格子、尺子、视图哈希、消息 ID 顺序和调用坐标，`groups` 保存映射后的结果。对应 `calls/`、遥测和 `transcript.json` 可回读原件。
- 每个教学周期单列一组，标为 `support_chain` 或 `counterexample`。同组已观察槽按角色和时间严格递增，同一维度各组跨度不得重叠，机会引用也参与跨度计算。可审计的无损重排仅限槽内引用和互不重叠的整组。2 分至少需要一条所有槽为 `observed` 的支持链。交还主动权的末段证据还须位于零基下标 `floor(消息数 × 2/3)` 起的末三分之一。
- `observed` 引用发生的行为。`not_observed` 引用具体机会，且机会消息本身或之后必须能看到该槽预期角色发言。回读时还要核对该发言是否真有机会表现该行为。`not_applicable` 仅允许用于 `representation_pivot` 无机会，按现行口径仍为 0 分。`insufficient_information` 说明未定档原因。本地校验允许带这个槽的 0 分同时具有观测或机会引用，需靠回读确认该证据确实支持低档。历史文本引用走兼容回归，不能根据近似文本补造绑定。

## E2 坏教师的目标维度

| 格子 | S0-06 要回读的行为 | 目标维度 |
| --- | --- | --- |
| `answer_dump` | 首个正式答复给出完整解 | `productive_struggle` |
| `lecture` | 教师长讲并持续代做，学生末段跟听或复述 | `agency_handoff` |
| `sycophant_close` | 附和后收尾，缺少解释或迁移检查 | `verification_or_transfer` |
| `no_teach` | 学生暴露 AE 与垂距的混淆后，教师仍只鼓励 | `misconception_repair` |

E2 的机器条件要求四个目标维度各比同 run 的正常对照低至少一档，且两侧均有引用。人工逐项判断机会和行为。旧自检为 `no_teach` 使用学生变化，当前改为直接检查可回读的教学行为。

## 已知问题

- `no_teach` 的低档可能混合「没有教学机会」与「有机会但错过」。当前校验能确认预期角色在可见窗口发过言，无法确认学生是否暴露了可修复的误解。若找不到真实机会，报告不可判定，不能用低档宣称尺子命中。结构化区分需要另改 schema、评分及对照逻辑。
- 旧库 S0-06 的 `answer_dump` 在 `representation_pivot` 获 2 分。旧裁判把完整解后的几何重讲视为受阻后的有效换法。这是需人工复核的历史偏差。证据索引为旧库 `docs/exec-plans/completed/2026-11-17-trajectory-evidence-contract.md:19,25,256`，原件路径见该索引的 `answer_dump-retry`。新 E1 的同维度记录 1 分，可回读 `runs/e1-real-numbered-two-cells/answer_dump/judge.json`。两笔分数保留原样。判断换法需核对原讲法受阻及学生理解，不能仅凭几何表示变化或坏教师标签定档。

## 学生变化（历史口径）

旧 `learner_change` 测量模拟学生的认知、元认知、非认知状态变化，内部权重为 50/25/25。状态更新依据学生在对话和私有小测中展示的证据。独立解释、应用、自查和迁移才提供正掌握度证据，附和和复述无此信用，透露会折减信用。适用小测缺少状态更新时无法测量。题目本身无此项，或小测答案键错误、可照搬同题、无法测到目标技能时，须按题记录排除原因，且固定排除快照才可比较。历史 `no_teach` 曾观察到学生自行进步，状态增量不足以归因给教师。

当前生产入口只生成学生公开回复。私有状态更新、独立小测和 `learner_change` 字段均未接入。若后续启用，需为测量和排除状态单独定义 schema、证据边界与身份，并另行验收。当前报告不生成估计值或以教学维度分数代填。
