# 二元尺子 `e1-binary-v1`

第二轮 ① 的候选尺子由 `S1-binary` 入口使用。它采用 `judge-output-v3` 和 `evaluation-identity-v3`。首轮 E1、E2、训练及已冻结入口使用各自原有的 v3 契约。

## 评分维度

| 维度 | 裁判的是非题 | 代码算分 |
| --- | --- | --- |
| 误解修复 `misconception_repair` | M0 学生明确提出具体错因且教师能回应；M1 教师给辨析依据；M2 学生独立修正同一错因；M3 全解抢先替代修复 | M0=No 得 N/A。M3=Yes 或 M1=No 得 0。M1 先于同链 M2 得 2。其余得 1。 |
| 增加与撤去支持 `support_escalation_and_fading` | S0 学生受阻或做成一步且还有可推进的步骤；S1 在同一卡点增加仍留步骤的支持；S2 成功后归还决定并持续放手；S3 首个实质回应给全解 | S0=No 得 N/A。S1/S2 皆 No 得 0；两项同链且 S3=No 得 2。其余得 1。 |
| 交还主动权 `agency_handoff` | A1 学生在开场后实际执行独立的实质步骤；A2 学生自选方法、候选解或检验，并说出理由或后果 | A1=No 得 0。A1 实做 A2 的末段选择，相同消息或下一条学生消息，得 2。其余得 1。 |
| 保留有益试错 `productive_struggle` | P0 有未完成的实质任务且教师能回应；P1 首个实质回应揭底；P2 针对卡点给提示且学生实际尝试；P3 已有实质回复，教师又对下一卡点紧接着过早替做 | P0=No 得 N/A。P1=Yes 或 P2=No 得 0。P3=Yes 得 1。其余得 2。 |
| 表征转换 `representation_pivot` | R0 学生明确卡在教师已用的表征；R1 教师针对同一关系换表征；R2 学生用新表征解释、推导或发现具体问题 | R0=No 得 N/A。R1=No 得 0。同链 R2=Yes 得 2。其余得 1。 |
| 验证或迁移 `verification_or_transfer` | V1 教师提出未代答的概念检查或变式；V2 学生独立解释或完成变式 | V1=No 得 0。同一检查的 V2=Yes 得 2。其余得 1。 |

总分记录为 `points / possible`，其中 `possible = 2 × 适用维数`。`rate` 为两者的比值；无适用维时为 `null`。当前 A/V 恒适用。技术故障使整格无判决。0 分、N/A 和技术缺分各有单独含义。相同尺子的同题配对只用两侧共同适用的维度，任一侧目标维不适用或缺分则该目标不可判定。v3 的固定 12 分和新版的适用分率采用不同的比较口径。

## 引用与原件

[`binary.mjs`](binary.mjs) 定义题目、证据位和规则。模型返回 `answers`，每题给 `answer` 布尔值，以及 `evidence` 内按角色命名的 1 基序号或 `null`。No 的所有证据位均为 `null`。Yes 至少有一条对应原字的 `#n`。出站 JSON Schema 将每个证据位限制为相应角色的消息序号，本地复核角色、顺序、同窗锚点和末段位置。首个实质回应、学科内容及是否独立仍须回读。教师声称学生做过的事只能出现在教师消息中。

`judge.json` 保存 `binding` 和 `verdict`。`verdict` 包含逐题布尔值、证据序号、映射的原消息 ID 和代码算分。`binding` 保存完整窗口的哈希及消息顺序，适用于 Yes、No 和 N/A 的回读。`--verify-run` 按原始调用重放判决，核对对话哈希、短引用、进程和评测收据。

## 候选准入

真实 `S1-binary` 仅接收已核对的 `e2-real-20261119-06` 五份冻结公开对话。每份复判三遍，一次进程逐格调用。预检验证原件并给出共享预算。真实启动前提供包含构造预期答案的 `--preregistration` 文件及 `--preregistration-sha256`。运行保存该文件及 SHA256。`ruler-expand --phase test` 的冻结准入维持 v3 的身份核对。候选尺子尚待后续资格验证及冻结。
