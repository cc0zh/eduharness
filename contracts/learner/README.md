# Learner

`schema.mjs` 校验单个 JSON 文档，不截取看似有效的前缀。话语进入公开对话，画像不进入教师输入。

`profiles.mjs` 定义三种高压学生。`executeCell({ learnerVariant })` 显式选择 `stubborn`、`answer-seeker` 或 `pretender`。省略该参数沿用原提示和任务画像，不改回归集。高压画像身份由私有提示与行为规则散列。题目的已知、未知与开场仍由输入任务所有。学生只从私有画像与既有公开话语推断下一步，不持久化掌握度，不插入额外消息。完整对话仍为九条。从第三次学生回复 #7 开始计末三分之一。

`hard-learner-fidelity` 是独立保真小样入口。它用冻结的八条前缀生成 #9，再将公开话语交给非学生模型家族逐条审核。`fidelity.mjs` 校验审核格式、顺序和引文。审核不改写学生回复，不进教师输入，不出教师分数。是否教得会和是否守住画像由预登记决定。[运行步骤](../../docs/runbook.md#阶段-2a-高压学生保真)

审核 v4 记录实际尝试、带依据的修正和可能的新知识原字，由本地代码还原阶段标签。引文须属于 #9，教师此前已经说过的同一原字不计为跃迁。历史审核仍按原身份复核。画像修订按当前教师回合选择行动，历史回复用来确认已尝试和已修正的内容。
