# 按要用的维度冻结尺子

**现象。** 在同一份锁定标签及 15 条冻结训练对话上，只复评一次。合并六维的 90 个有效配对后，线性加权 κ 从 v3 的 0.741 降至 v4 的 0.686，精确同档从 71/90 降至 67/90。两版均未通过训练一致性线。按当时的一轮处置规则先冻结了 v4。

**根因与边界。** 已证实 v4 只补「验证或迁移」的 0/1 档例子，不改分档定义、不重标。做完一次修订就冻结复评版，与下游实际要用哪个维度的可靠性是两件事。一次复评不能证明是新增示例造成 κ 下降，也不能证明 v3 普遍优于 v4。

**证据。** `3bd3b17` 的尺子变更、`d5b3553:docs/status.md:3–9`，及 `runs/ruler-train-score-v1/`、`runs/ruler-train-rescore-v4-20261120-01/` 的 `calibration-results.json`。`e34d8c7:docs/status.md:30–45` 记录目标维择版规则和结果。

**修复或现状。** 按两项目标 `agency_handoff` 与 `verification_or_transfer` 的同档数择版，平手才比两维平均 κ。v3 为 19/30，v4 为 17/30，差在主动权两格，迁移同为 7/15，故改冻 v3。择版不改训练未通过的结论；两版迁移维 κ 都低于 0.60，后续只把该维分数作参考。

**预防。** 从下游要判定的行为倒推目标、择版规则和平手规则，再做训练复评。合并 κ 或总分只作描述，不替代逐维一致性或通过线。允许「不改版」和「冻结但未通过」。
