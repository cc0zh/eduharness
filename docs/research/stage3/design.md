## 2. 不变量与状态

- 公开顺序固定：#1 学生开场，#2/#3、#4/#5、#6/#7、#8/#9 各是一对教师/学生消息。保留角色、轮次、编号及投影。末三分之一仍从 #7 开始（contracts/judge/binary.mjs:101–105、src/binary-judge.mjs:14–17）。这个边界只供评测使用，不是教师动作的触发器。
- 拟定：每次教师回复前，用当时的公开前缀判读最新学生消息。观察器不知道题库、答案、误解键、学生画像、裁判契约或分数。公开文本是证据，不是给观察器的指令。教师也不接触这些私有输入；工具私有结果不是学生证据。
- 拟定：内核持有会话状态。观察器只报告带引用的事实候选，纯函数负责应用观察、选动作。以下状态都是对公开行为的推断，不宣称测到学生内在掌握度。

| 状态 | 输入证据与更新责任 |
| --- | --- |
| 误解：未知／未观察到／未修复／已修复 | 观察器引用学生具体错因；内核以公开消息号与错因短引文作为锚点。只有学生在后续消息以同一错因给出未被代做的关键推理才修复。复述、改数、同意不算；新错因或旧错因复发阻断收尾。可有多个未解决锚点，每轮处理一个。 |
| 当前尝试：未见／只提议／尝试／有独立推理；另记口头认可、索要答案 | 观察器给最新学生消息引文，并对照此前教师是否已提供关键步骤。尝试可以错；猜中或按给定式子代数不算独立推理。自己提出理由或方法与实际执行分开记录。单说懂了不覆盖任何未解决状态。 |
| 当前卡点及最近的支持或表征 | 观察器引用教师实际给出的帮助和学生此后对同一关系的卡点或进展。内核保留这条链和上次交还的任务；换表征必须回应先前教师用过的表征，学生只说“懂”不算采用。 |
| 验证：未发起／待回应／未验证／不可判定／通过 | 内核记录刚发出的检查锚点。观察器核对教师公开正文确实留下关键推理，以及后续学生是否独立说明正确依据或完成改条件的题；锚点须是同一检查。错误、猜测、复述或未作答不通过；无法核对为不可判定。误解复发或新反证使旧通过不可用于收尾。 |

拟定：观察用封闭枚举和短证据槽，不返回分数、行动建议或自由推理。边界用完整 JSON 解析，校验长度、字段、角色、顺序、当前学生消息、同链锚点及短引文确在原字中。动作意图只用于关联待办；模型的观察须核对教师实际做了什么。结构校验不证明语义正误，也不保证教师按指令生成；存疑记未知，真实 A/B 另盲核误收尾和代做。

### 判定方案（下列风险与成本为推断）

| 方案 | 成本与延迟 | 评测身份 | 被话术欺骗的风险 |
| --- | --- | --- | --- |
| 教师自评 | 把观察和答复放同次结构化输出，计划内新增 0 次逻辑调用，但多输入和输出。代码只能事后检查选择与规则是否一致，不能先选动作再生成；要先选就须额外续调。格式拒收可能触发重试。 | 变更教师提示、输出契约和解析；若加续调或改预算，还要绑定调用策略和上限。 | 同一生成既宣称证据又给出答复，易把自己的解释当学生掌握，或选了收尾再找理由。 |
| 独立小分类调用 | 每个教师回合前至多 1 次，完整对话最多额外 4 次。无工具和重试时，含学生与裁判的每格常规调用从 9 次到 13 次。不在 #9 后补判。每轮多一个串行等待；拟用短输出、独立 deadline、0 重试（含 429）。额外请求输出上界 4 × 单次上限，不含额外输入和价格。 | 单列 teacher_observer 路由、提示、输出 schema、推理、超时、尝试和总预算，再绑定转移策略。教师和裁判路由不换。 | 判读先于本轮生成；只能以学生原话更新学生行为，教师宣称只能证明它说过，不能当作学生证据。仍可能误判复述或把同一检查串错，须用盲核和负对照检验。 |

**推荐（推断）：独立小分类调用。** JavaScript 能在答复生成前拒绝无证据的收尾，不让生成模型同时给自己判过。隔离的是职责和输入，不假定小模型更准。先锁短超时、预算并实测误判和尾延迟；若不合格，不在留出集上改用自评。

## 3. 转移规则（拟定，按序首条命中）

全局约束：留一个学生能做的实质动作。允许给辨析依据或局部提示，但不宣布原题最终答案或代做本轮留给学生的关键推理。表中的题号是设计审查索引，绝不进入教师或观察器提示、分支条件或目标文案。

| 优先级与触发条件 | 本轮动作与下轮判法 | 对应二元尺子问题 |
| --- | --- | --- |
| T01 学生要完整过程或答案 | 交还任务。围绕现有卡点给一个可试步骤；若已有进展，让学生自主选方法或自检。不给结论；重复索要也不代做，下一轮看实际尝试。 | P0/P1/P2/P3、S3、M3、A1/A2 |
| T02 本轮观察缺失、无效或不确定到无法定位 | 只做一个短诊断或请做一个小尝试；保留已知未修复锚点，不晋级、不称掌握。 | M0、P0/P2、V2 |
| T03 教师用过某表征，学生明确仍卡在同一关系，且该卡点没有换过表征 | 换表达结构，不是换数字或复述。留一个映射或推导给学生。没有合适的新表征时只缩小一步诊断，不虚记转换。只有学生用新表征解释、推导或指出具体问题才记采用。 | R0/R1/R2、M1、P2 |
| T04 已有提示，学生仍卡在同一步，且不走 T03 | 加一档支持，例如给更具体的对比，让学生完成剩余的关键一步；首次提示不算加档。不给完整解，成功后才撤支持。 | S0/S1、P2/P3、M1/M3 |
| T05 有未修复的具体误解，未触发更高优先级 | 给辨析依据或一个反例测试，让学生自己修正该错因。下一轮仍错就保留开放，不跳收尾。 | M0/M1/M2/M3、P2 |
| T06 检查未通过或学生只有口头认可 | 针对缺的一环补救，留一个新的概念追问或小检验；若卡在旧表征优先走 T03。不给检查的关键推理，不称已验证。 | V1/V2、M2、P2/P3 |
| T07 仅最后一轮；最新学生证据通过当前检查，有独立推理，无未修复或未知的诊断 | 可以确认学生已给出的理由并收尾；不重做题，不替学生总结新的关键推理。学生末答仍照常生成。 | V1/V2、A1、M2 |
| T08 无开放误解，有足够进展可以查概念，且不满足 T07 | 留一个“为何适用”或只改一个条件的检查，条件允许就早于最后一轮。不把原题继续列式当迁移；检查留给学生独立完成。 | V1/V2、A1、P2/P3 |
| T09 学生独立做成一步，仍有实质步骤且尚不宜查概念 | 撤去支持，交还方法选择或检验；下一轮核对学生自己提出理由并实际执行，教师不再接管有关步骤。 | S0/S2、A1/A2、P3 |
| T10 其余情形，含首次拿到题、未暴露具体错因 | 用一条诊断问题或针对可见卡点的首个提示，给学生留一个可做的尝试。 | M0、S0/S3、P0/P1/P2 |

拟定：只给生成器本轮动作，不累加历史目标。第 4 轮未满足 T07 就照表补救、追问或交还；耗尽轮次不是掌握。#9 可给离线裁判提供新证据，运行时不再追加教师轮、分类调用或结业宣称。stop 只结束本次生成；私有工具续调不重复观察、不推进公开轮次。

## 5. 风险与降级

- 推断：8 道开发题易导致针对题族或学生说法调规则。只修能在不同题族用无题干 faux 复现的机制；最多两版，已见题只做回归。留出结果不反调提示、判线或尺子。
- 推断：分类假阳性比多问一句更容易造成误收尾。观察超时或契约失败时记未知并走 T02，不追加重判，也不切换基线。预算、配置、取消及教师生成最终故障按基础设施故障处理；不编造答复或分数，不补第 5 轮。结构化证据只能排除错绑，语义仍待回读。
- 推断：连续补救可能比基线更啰嗦。每轮只留一件可做的事，不口播状态，不为“验证”加自我表扬。以教师正文字符数、每轮响应耗时和降级率对照基线；超出登记护栏不采用。

## 待拍板

### 1. 谁判定教学状态，愿意为判定增加多少等待

1. **背景。** 旧教师的 finishTurn 在模型返回 stop 后晋级，不检查学生是否修正或通过验证（src/teacher/session.mjs:40–54、59–69）。现有正常格用 4 轮，教师每轮至多 2 次逻辑调用以容纳工具续调，未单列观察器（config/e1.mjs:2–7，src/run.mjs:111–129）。
2. **为什么现在拍板。** 推断：这个选择决定代码能否在生成前选动作，也决定调用角色、输出契约和超时降级路径。开发候选前先定机制和可接受的等待，避免用不同调用策略得到的结果混作同一候选。
3. **选项做法。**
   - **甲：同次教师自评。** 同一教师响应返回观察、建议动作和公开答复。内核用观察重算动作，拒绝不一致的整份答复。只在旧教师的额度内重试，耗尽则记故障。登记开发候选时锁结构化输出契约，不为自评增加工具续调。
   - **乙：独立小分类。** 每轮先判读公开前缀，再由内核选动作，教师按该动作回复。每轮最多 1 次分类，包括 429 在内不重试。为分类单列单次输出上限和截止时间，运行前登记四轮总额度。分类超时或契约无效就记未知并问一个小步骤。
4. **各选项影响（推断）。**
   - **甲。** 评测身份：变更教师提示和输出契约。成本与延迟：不新增计划调用，结构化正文和拒收重试仍会增加用量或等待。面试叙事：能说明事后校验，不能说代码在答复前门控。项目 2：可复用 reducer，但联合生成适配器绑定该输出契约。过拟合与话术：容易在小开发集上调出“自评与回复一致”，两者仍可能一起把教师的解释误当学生掌握。
   - **乙。** 评测身份：另绑定观察器路由、提示、契约、推理和额度，教师与裁判路由不换。成本与延迟：每段最多多 4 次尝试，新增请求输出额度最多为单次上限的 4 倍，每轮多等一次判读；实际延迟和费用未测。面试叙事：可解释“证据先于动作”和失败降级，不宣称小模型更准。项目 2：可直接导入同一内核，另注入观察与生成。过拟合与话术：引用校验能拒绝只引教师宣称的学生证据，但仍可能在开发集上拟合固定表达或误把复述判为独立推理。
5. **推荐（推断）。** 选乙。它把状态判定和答复生成分开，能在生成前拦住没有证据的收尾。先锁单次截止、输出上限和端到端延迟护栏；若受控开发验证不过，不在留出阶段换回甲或放宽额度。

### 2. 采用线只设一个主目标维，还是要求两个都过

1. **背景。** 首轮把交还主动权和表征转换列为主目标。实际 10 题基线的表征转换已到 2.00；行为命中从 4/5 到 5/5，只多 1 题，原线要求多 2 题（runs/harness-ab-v1/ab-report.md:9–19、38–58）。本轮采用线仍待填，依据是同批 8 道 dev 题旧基线的结果摘要，不是上述历史分数（prereg-draft.md §2、§4）。
2. **为什么现在拍板。** 推断：须定下判几项才算采用。具体目标、差值、覆盖和退化护栏等同批基线上限空间查完再填，但须早于查看候选表现或打开留出。否则可能再设出不可达的门，也可能看完结果才挑有利维度。
3. **选项做法。**
   - **甲：一个主目标维。** 只用基线摘要锁定一个已通过尺子资格、共同适用机会与改善余量充足的维度。要求同题分差及独立行为同时过线，其余维度设非退化护栏。固定话术对照、旧题回归和运行护栏。
   - **乙：两个并列主目标维。** 用同一批基线确认两维各有有效覆盖、足够余量和可盲核的学生行为。分别锁判线，要求两维同时过，不许一维涨分抵另一维失败。其余护栏与甲相同；凑不够两维就不启动留出。
4. **各选项影响（推断）。**
   - **甲。** 评测身份：锁一项主目标及护栏，改变判线要重锁预登记哈希，不换尺子。成本与延迟：每格仍由一次逻辑裁判调用给出全部 19 项（src/binary-judge.mjs:3–7、14–19）；主目标的人工核对范围较集中，不影响教师回复延迟。面试叙事：只能说该维过线，其余是防退化。项目 2：内核可复用，其他教学能力仍需补验。过拟合与话术：容易把一个指标当优化目标，须用独立原话和话术负对照拦下只涨分的候选。
   - **乙。** 评测身份：锁两项主目标、各自覆盖和判线，另有预登记哈希，仍是同一把尺子。成本与延迟：不增加逻辑裁判调用或教师延迟，需要多核一条行为证据链。面试叙事：两维都过才可分别讲结果；任一不可判定就不宣称双维改善。项目 2：导入接口不变；两维都验成时能援引更多证据。过拟合与话术：单维虚高不能单独过线，但小批次更可能被某一维封顶或缺机会卡住。为凑第二维挑题会增加过拟合风险；两维机评分也不能替代话术对照。
5. **推荐（推断）。** 默认选甲，保留独立行为硬门和非退化护栏。先证明一项可判的真实改善，比在小批次上押两维更容易解释。如果同批基线证明两维的机会、证据和余量都足够，再在锁线前选乙。任何目标都不可判时不启动留出，不用总分顶替。

### 3. 谁做独立盲核，何时授权唯一一次留出

1. **背景。** 首轮是知道侧别的执行者 AI 在揭分前回读，不是独立人工盲核（runs/harness-ab-v1/behavior-audit.md:1–3）；话术副本的学生正文未变，但出现逐题分数波动（runs/harness-ab-v1/ab-report.md:52–54）。路线图只允许一次留出三臂对照（docs/plans/roadmap.md:35–39）。本轮草案未授权解封，尺子冻结也仍有前置条件（docs/status.md:19，prereg-draft.md §2–§3）。
2. **为什么现在拍板。** 推断：第一次消费留出不能撤回。若没有独立核对或事先锁定的失败处置，就无法用第二次机会补出同等强度的未见题证据。先定负责人与准入，再决定是否消耗这一次运行和预算。
3. **选项做法。**
   - **甲：指定独立人工盲核人，齐备后授权。** 保管方锁定计划摘要，获准后只有隔离运行者读封存题，设计者不读。尺子和学生保真合格、候选与预登记锁定、盲核范围和硬额度经授权后，只启动一个 sealed 批次；基线可行性不足即停止。由未参与候选调试且未见侧别、机判分数和理由的人盲标公开原话，锁标签后揭盲；话术侧只复判基线副本，不再生成学生答复。
   - **乙：暂不授权，停在开发和已见题。** 盲核人员、准入证据或预算任一不足，就不读 sealed、不启动任何留出臂。只保留已获准的 faux、dev 和旧题回归结果；不得以执行者或 AI 复核代替独立盲核，不宣布采用。
4. **各选项影响（推断）。**
   - **甲。** 评测身份：三臂分别绑定计划、冻结条件、预登记及收据，C 另绑定 B 原件。成本与延迟：三臂跑齐、无工具续调和重试时，每个计划配对为 23 次逻辑调用（B 9、S 13、C 1）；实耗以收据为准，盲核推迟结论，不增加在线回复等待。面试叙事：可按结果讲采用、拒绝或不可判定，不把单批写成长期学习效果。项目 2：可复用内核和回归门禁，只有过线时才把本批证据用作采用依据。过拟合与话术：锁线和隔离防止用留出调试，盲核与 C 检查虚高；单次波动或话术字面露出侧别的风险仍存在。
   - **乙。** 评测身份：只保留已授权的开发或回归身份，不产生留出身份和收据。成本与延迟：当前零留出调用和留出盲核工时，正式判优顺延；不改变内核运行延迟。面试叙事：只讲设计或已证实的开发机制，不讲未见题改善。项目 2：可按接口做原型，不能把新状态机当经留出验收的默认版本。过拟合与话术：不消耗未见样本，但开发集过拟合与尺子抗骗都尚未得到独立验证。
5. **推荐（推断）。** 选甲的准入方式，先明确盲核人，满足条件才单独授权费用和启动；任何条件未齐就执行乙。保住一次有效的留出，比抢先拿到一套不能支持采用的分数更重要。
