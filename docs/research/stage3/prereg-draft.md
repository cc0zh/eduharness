# 阶段 3：三臂 A/B 预登记草案

状态：草案，不授权读受保护输入、解封、实施或调用模型。“待填”必须在正式验收前填定并锁定。版本、阈值和本文登记未核定，本次未发模型请求。以下是拟定协议；推断单列。

## 1. 问题与对照臂

问题：同一高压学生条件下，动态选教学动作是否让学生更常独立产生证据，同时避免提前代做和回归退化？推断：改观测与分支可能改善行为；不是已证实效果。三臂按同题、同画像、同重复编号配对。

| 臂 | 唯一干预 | 冻结内容 |
| --- | --- | --- |
| B · 旧线性基线 | 用旧 normal 四个目标按 stop 进阶，不用历史 improved，不加观察器。 | 基线源码和提示指纹：待填。 |
| S · 新状态机 | 独立小观察器、证据驱动的转移和每轮动作提示。教师、学生及裁判路由及各自调用上限保持与 B 相同，不把差异归因于单独一条转移。 | 候选版本、状态契约、观察器配置及硬额度：待填。 |

## 2. 数据隔离、上限空间与选版

1. 登记分阶段访问、题族隔离、固定计划与基线可行性算法。设计期不得读取 dev 题干、sealed 任一副本或 runs/stage2a-* 的学生回复原件。由保管方给出不含题干或学生原字的清单摘要和锁定凭据；摘要不用于挑留出题。二元尺子冻结与三类高压学生保真均是准入条件，不假定已过。
2. 先取得能力集的 **同批 dev 8 道题旧线性 B** 上限空间检查（同画像、冻结尺子、模型和预算、同一预定计划）。可由隔离执行者按已锁的基线协议只交核验过的聚合结果；只有身份与计划完全对齐才可用已有 B 汇总。没有相符汇总则留待授权，不能用历史 25 题或首轮分数替代。本稿没有进行检查。
3. 只看 B，逐维报告计划格数、有效格数、适用数、无机会与证据不明数、0/1/2 档数，以及 B 有效适用格的最大分差总量 Σ(2−Bᵢ) 和均值上界。若允许配对覆盖降至 k 格，取不足满分最多的 k 格作配对均差的乐观上界，并另外约束机会流失。行为也报计划分母、机会、命中数和可增加的命中数。B 机会或余量不足的维度不作正向目标。用此结果填写第 4 节，不看候选或留出表现挑维或调线。
4. 锁定采用规则和开发放行线后才授权接触 dev 题干。限固定 dev 的 8 道题调试；旧的已暴露题（含旧 25 题）只作配合型回归，不混入开发正向分母或留出。最多两版候选，首版计入。每版开启前登记指纹和改动理由；选第一版通过已锁开发与回归门槛的候选；两版都不过则不采用、不打开 sealed。
5. 数据保管方锁定 sealed 的计划摘要；在候选、采用线、盲核表和预算签字固化前，任何副本均不打开。留出只启动 **一次**三臂批次。先用该批 B 在隔离端做最终上限空间复核，只按已锁规则核对是否可达；若锁定的主目标或行为门因封顶、机会或覆盖不足不可达，记不可判定，停止余下臂，不换题、目标或阈值。若可达，沿用原 B 完成 S、C，同期按预定计划跑回归集。已锁调用级重试属于本批；不补跑故障格、不另开 run 或重判求通过。

推断：上限空间只说明“理论能上升多少”，不预测候选效果。首轮按另外一批低均分选维，实际 10 题 B 的表征转换全满（2.00）。行为门要多 2 题，而固定五题的 B 已命中 4/5，实际至多新增 1。填写时须同时检验绝对门、相对门和覆盖要求可共存。保留首轮“不靠局部上涨判优”、分别查分数与学生原话的做法，不照搬旧数值。

## 3. 计分、盲核与收据

- 保留 19 道是非题、证据链和六维计算原样。单格适用分率为 points / (2 × 适用维数)。锁定配对键，逐目标维计算 S−B、C−B 的配对均差；只比较双方均有效且共同适用的维度，另报三臂共同配对的敏感性读数。综合差只用同题共同适用维的分率。A/V 恒适用；N/A、0 分和技术缺分分栏，不代填。覆盖按计划分母报，列出 B 有机会却在 S 或 C 消失的格，不能靠删机会提高分率。
- 拟由未见侧别、身份、模型判分和理由的独立人，按预先锁定的范围（建议全量留出）逐份盲核公开对话，先锁标签和消息序号再揭分。按机会核对：同一错因的独立修正、实做而非口头认可、学生自选并执行检验、有依据的解释或近迁移、表征转换后的映射、是否提前接管。AI 预标后复核不算独立盲核。记录话术字面可能暴露侧别的局限。
- 逐题列 19 位及引用与原文，用全对话核对独立性和锚点。C 先过机械差分：除 #8 加尾句和独立 ID 外，角色、轮次、各条正文不变。再核对 C−B 新增 Yes、同分换引用、翻档，重点查 M2、A1、A2、R2、V2。若新增 Yes 引用的整条链没有合规学生证据，盲核确认后记为假阳性。只有一次复判不能区分孤立翻位来自话术还是裁判波动。
- 每侧独立且不嵌套的 run 根。登记冻结尺子及输出契约、语料/画像/计划摘要、各臂允许变化字段、来源哈希、硬额度和预登记 SHA256。核对干净 HEAD 的 npm run check 收据和真实预检；另经 ask_user 授权调用数与 token 上限才用 --confirm-cost。保存启动/进程/评测收据、判决、对话、用量与失败位置；--verify-run 回放各侧。acceptance 只表示机器产物齐备，不是采用。

## 5. 预定结论

| 结果 | 结论 |
| --- | --- |
| 证据链与覆盖合规；S 主目标和独立行为都过线；非目标/旧题/运行护栏过线；C 的分数门与证据门均未被话术骗过 | 采用锁定的 S。结论只覆盖本批公开行为，不证明跨次稳定性或长期学习。 |
| 证据足够且 S 未过目标或行为门，含只涨分、只涨行为、同档或倒退 | 不采用，继续 B；分别报告涨分未获行为支持、行为改善未获尺子支持，或未观察到改善，不把局部结果当通过。 |
| S 通过目标但有教师代做、未修复先收尾、回归或成本/延迟等护栏不过线 | 不采用，继续 B；标明失败护栏，不用总分抵消。 |
| C 机器门超线或盲核确认假阳性 | 本次门禁不能排除话术影响，不采用 S；查原话、换引用与裁判波动，不改线、不用这份 sealed 修后复验。 |
| 尺子/保真未准入、上限空间或机会不足、缺少盲核、污染、身份不一致、技术缺分/中止导致无法验线 | 不执行或不可判定，保留 B，不采用；报告停在哪个条件，不归因于 S 教学变差。 |
