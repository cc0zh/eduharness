# 配对误差、版本比较和功效

## 最小独立单位是题或题族

**出处** Evan Miller，*Adding Error Bars to Evals: A Statistical Approach to Language Model Evaluations*，2024，§2.1–2.2、§4.2、表 4、附录 A。[原文](https://arxiv.org/html/2411.00640v1)；`docs/scenarios.md:38–41,83–87`。

**具体内容** 独立题的平均分 `x̄=Σxᵢ/n`，`SE=s/√n`，`s²=Σ(xᵢ−x̄)²/(n−1)`。大样本 95% CI 为 `x̄±1.96SE`。同题两版用 `Dᵢ=Bᵢ−Aᵢ`，`Var(D)=Var(B)+Var(A)−2Cov(A,B)`，对 `D` 求差均值和 SE。相关题用 Miller 式 (4) `SE_cluster²=SE_CLT²+Σ_cΣ_{i≠j}(Dᵢc−D̄)(Dⱼc−D̄)/n²`。表 4 的 DROP 聚类 SE 为 1.34、朴素为 0.44，约 3.05 倍。RACE-H 比率 1.10，MGSM 1.88。固定每题等权时也可先把每题内反复运行的差值求平均，然后以独立题均值算 SE。共享模板、题干或共同来源的任务可能还要以题族为簇。

**对 TeachArena 的意义** E2 的 `n题=1`、每格 `n对话=1`，同一正常格被四个目标比较复用。此处只报告「该运行、该题、该画像、该尺子下，4 项预登记方向均达到至少 1 档，人工回读了对应行为」。一题不能估跨题 SE，拆成轮次、维度或推理调用也不行。三次冻结复评估的是固定对话下的裁判波动。重生成学生教师对话估的是固定题下端到端波动。两者都不能替代增加独立题。

## 根据结果类型选检验

**出处** Miller（2024）§2.1、§4.2；SciPy 源码 `bootstrap(paired=True)` 与 `permutation_test(permutation_type='samples')`；Quinn McNemar（1947），*Note on the sampling error of the difference between correlated proportions or percentages*，「未读原文」，实现参照 statsmodels `mcnemar(exact=True)`。[Miller 原文](https://arxiv.org/html/2411.00640v1) · [SciPy 源码](https://github.com/scipy/scipy/blob/v1.17.0/scipy/stats/_resampling.py) · [McNemar 源码](https://github.com/statsmodels/statsmodels/blob/main/statsmodels/stats/contingency_tables.py)

**具体内容**

| 目标 | 单位与操作 | 适用条件 |
| --- | --- | --- |
| 0–12 总分或预登记单维平均档差的区间 | 用同题成对差，按题或题族有放回抽样。每次整簇保留旧版、新版和重复。做 10,000 次，报告差和 95% CI | 簇足够且覆盖目标总体。少数簇的区间不稳，一簇重抽会产生假窄的零宽区间 |
| 检验同题两版可交换的原假设 | 在每个独立题内交换 A/B，等价于翻 `Dᵢ` 的符号，或将整题族一起翻。统计量为 `abs(mean(D))`。小 `n` 枚举 `2ⁿ` 种，大 `n` 用 10,000 次蒙特卡洛和 `(b+1)/(M+1)` | 标签交换须有随机化设计或原假设下的可交换性。仅假设总体均值为 0 不足以保证该精确检验成立。如独立题只有 1 个且差非零，双侧精确 p=1 |
| 预登记二元通过状态改变 | 记录旧失败新通过 `b` 与旧通过新失败 `c`。在独立配对下，精确 McNemar 条件于 `b+c`，检验 `Binomial(b+c,0.5)` 的双侧尾 | 例如 `b=8,c=1` 时 p=`2×(1+9)/512≈0.039`。无法评判和基础设施故障单列，不直接转成不通过 |

**对 TeachArena 的意义** 先指定主指标，例如「有教学机会的对话中，目标维度 `B−A` 的平均原始档差」。度量 0/1/2 的均值隐含等距编码，报告三档转移及升、平、降作核查。总分的 `0.5` 是另一种单位。若是固定同一题上多次重复得 `0.5`，该数只描述固定题。若预登记多维共同检验，用 Holm 校正或说明探索性质。必须一并给出样本量、实际包络、效应大小、实用门槛和有效配对率。缺分时列出两侧缺失及原因，对照完整配对和包含边界分的敏感性分析。

## 0/1/2 档如何换算经验样本量

**出处** Miller（2024）§5 与附录 B–C，式 (9)、(10)；`contracts/judge/README.md:9–20`。[原文](https://arxiv.org/html/2411.00640v1)

**具体内容** 双侧 `α=.05`、功效 `.80` 下，独立配对题近似 `n=ceil[(1.96+0.842)²·σ_D²/δ²]≈ceil[7.85·σ_D²/δ²]`。Miller 的示例用 `σ_D²=1/9`、`δ=.03`，约 969 题，方差是假设。TeachArena 的单维 `D∈{-2,-1,0,1,2}`。总分 `D∈[-12,12]`。以下假设 `σ_D` 都待先导复核。正态功效近似的很小样本行只作为量级提示。

| 主指标 | 最小关心差 δ | 假设 σ_D | 独立题估算 |
| --- | ---: | ---: | ---: |
| 单维平均档差 | 1 档 | 1.0 | 8 |
| 单维平均档差 | 0.5 档 | 1.0 | 32 |
| 单维平均档差 | 0.25 档 | 1.0 | 126 |
| 单维平均档差 | 0.5 档 | 1.5 | 71 |
| 六维总分平均差 | 0.5 分 | 2.0 | 126 |
| 六维总分平均差 | 0.5 分 | 3.0 | 283 |

示例分布 `P(D=+1)=.35`、`P(D=−1)=.15`、`P(D=0)=.50` 给 `δ=.20`、`σ_D²=.50−.20²=.46`，估算 91 道独立题。这些数字是规划例。样本小或同档多时，基于先导的三档配对转移模拟实际检验的功效，核对下尾与缺分。若六维都作为确认性假设，用 Bonferroni 的保守规划线 `.05/6`，`σ_D=1,δ=.5` 时约 49 道独立题。

**对 TeachArena 的意义** 先用约 20–30 道独立题做方差先导，每题每版生成 2–3 次，可在其中抽一部分冻结对话再各评 3 次。把每题真实差异的方差写成 `σ_between²`，题内单次配对差残差写成 `σ_within²`，独立同分布题内误差时 `Var(D̄题)=σ_between²+σ_within²/R`。例如分别假设 `.64` 和 `.36`，检测 `.5` 单维平均差时，`R=1,3,∞` 约需 32、24、21 道题。R=3 需要 72 对运行，R=1 只需 32 对，前者更利于估题内误差。若预算只允许加一种样本，方差先导后把钱分给能降低当前主要误差的层。即便总分平均差 `.5` 达统计显著，也需按预登记的教学效应阈值、分维方向和证据回读判断其实际意义。
