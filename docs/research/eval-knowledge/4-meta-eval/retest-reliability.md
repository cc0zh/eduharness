# 同一输入重复评分的信度

## 同一响应重放和重新请求回答不同的问题

**出处** `docs/status.md:94–110,116–124`；`contracts/judge/README.md:20,24–28`；`src/models.mjs:106–110,136–144,192–212`。

**具体内容** 完整真实五格的五份发布正文重放一致。重放检查保存的正文经解析和绑定是否得到同一产物。当前出站构造设 `temperature: 0`，业务层另有有限重试。冻结补评绑定源对话哈希，新旧两批已有对话的分数仍需检查是否使用同一尺子和输出契约。

**对 TeachArena 的意义** 当前正在做的三次复评按待完成实验记录。每格锁定输入哈希、评分身份、裁判模型和实际路由、解码与重试策略。一次逻辑评分允许重试，失败尝试计入可用性，不充当独立复评。三次都有效时才列三次完全一致指标。报告全部预定逻辑评分数、有效数和首次成功比例，保留失败行。

## 温度 0 仍有样本级漂移

**出处** Hongyu Chen、Seraphina Goldfarb-Tarrant，*Safer or Luckier? LLMs as Safety Evaluators Are Not Robust to Artifacts*，ACL 2025，§4 与附录 A 表 3。[原文](https://aclanthology.org/2025.acl-long.970.pdf)

**具体内容** 两次运行都用解码温度 0。GPT‑4 Turbo 的单样本偏好变化率为 5.7%，对应总体胜率变化为 0.5%；GPT‑4o 分别为 3.1% 和 0.6%。表中只有 Mistral 8×7B 单样本变化率为 0。作者列出底层推理的数值随机性作为可能原因，实验本身没有把漂移归因到某个特定机制。

**对 TeachArena 的意义** 关注逐对话逐维翻档和定向判定翻转。平均总分相同仍可能同时出现上调与下调。若另做温度实验，只在供应商实际支持且能核对的条件下做 0 与 0.3 两个固定条件，沿用同一批冻结输入，各自重复三次，比较翻档和失败率。把温度变更标作不同条件，不混进生产 retest。固定 seed 若路由支持，只是重复性条件之一。

## 三次相同才算完全一致，差档大小另报

**出处** Rajarshi Haldar、Julia Hockenmaier，*Rating Roulette: Self-Inconsistency in LLM-As-A-Judge Frameworks*，Findings of EMNLP 2025，§3–4，原文第 24990–24991 页。[原文](https://aclanthology.org/2025.findings-emnlp.1361.pdf)

**具体内容** MT-Bench 三次运行中，Qwen 3 在 61.3% 样例上三次给相同判断。MT-Bench 重复评分的 Krippendorff α 为 Llama 3.1 0.265、DeepSeek-R1 0.507、Qwen 3 0.563。这些是论文采样条件的自一致结果，和人工一致性是两组指标。

**对 TeachArena 的意义** 每维列三次原始档位、极差 `max−min` 和 3 个复评对中的同档比例。与总分的均值、样本方差 `s²=Σ(xᵣ−x̄)²/(R−1)`、标准差和范围一起报告。例如总分 `[8,9,9]` 的均值为 8.67、方差为 1/3、标准差为 0.58、范围为 1。按维汇总完全一致率、两档跨度率和复评间混淆矩阵。三次全部有效的五格每维只有 5 个对话，三对复评共享评分。报告原始计数，不拿 15 个复评对估独立误差。四组定向差逐次列 `Δr=normalᵣ−badᵣ` 和 `Δr≥1` 通过次数，单列同档、反转、缺分。若同一组跨 0/1 门槛，优先人工复核其证据，再考虑加复评。

## 换温度前先查原设定的波动

**出处** Justin Zhao 等，*Language Model Council: Democratically Benchmarking Foundation Models on Highly Subjective Tasks*，NAACL 2025，附录 B.1、B.4、图 16。[原文](https://arxiv.org/html/2406.08598)

**具体内容** 将每个回复对的「取众数判定的重复次数 ÷ 总重复次数」在样例间取均值。实验涉及 20 个模型，图 16 按每模型 10 次判定报告一致性，在温度 0 时平均一致性最高。温度 0 的条件中仅 13/20 模型在所有复评中完全不变。

**对 TeachArena 的意义** 三次评分的众数一致性会把 `[0,0,1]` 和 `[0,0,2]` 都记为 `2/3`。把两档翻转和引用核对列为独立指标。若提高温度只为估计噪声，报告为压力条件，将生产温度 0 的重复作为基线。
