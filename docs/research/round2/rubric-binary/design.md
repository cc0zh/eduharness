## 只让裁判判行为

一条冻结公开对话发一次裁判请求，一次返回 19 个布尔值及引用。代码做绑定、门控、定档和汇总。裁判不见旧分、条件名、私有学生状态、小测或答案键，也不写分数和分档理由。保留导师要求和学生做到的区分。参考 TutorBench 的可独立检查单项，不照搬它的单回复窗口、逐题权重或请求数假设。

依据：`docs/status.md` 的 v3 验证或迁移 κ 为 0.478；`runs/ruler-test-v3-real-01/test-report.md` 的 lecture 主动权数值命中 3/6、回读后 0/6；`runs/harness-ab-v1/ab-report.md` 的表征转换基线 10/10 满档，仅说明那一批封顶。`examples.md` 将 v4 复评的 23 格分歧逐类对应到新口径；v4 不是当前尺子。

`T` 为老师，`L` 为学生。单角色题只给该角色的行为记 Yes；其他消息只用于定位对象、确认引用前后关系、排除已给出的答案。结构题比较明确的前后事件。Yes 引原对话 `#n`，不引教师对学生行为的转述。No 是在完整窗口里未找到合格证据，不替代残缺原件或裁判故障。

## 引用校验与确定性算分

- 模型形状固定为 `{"answers":{"M0":{"yes":true,"refs":[1],"context":[]},"…":{…}}}`。19 个键和三个字段均必填，无额外字段。每个 Yes 按上表给恰好相应数量的整数，`?` 为 0 或 1；No 两数组为空。无自然语言理由、分档、总分或模型自报的 N/A。`#n` 是回读显示，线上传整数 `n`。
- TypeBox 的 strict 出站 schema 只声明固定对象、布尔、整数数组与封闭键集合。不依赖供应商执行条件分支、数组长度或跨字段规则。本地解析整条 JSON，验证 arity、范围、角色、去重、前后次序和末段 `n >= floor(2*消息数/3)+1`。跨题可复用同条消息。A1 若与 A2 同条，省略定位；若不同条，定位必须是其前一条 L。参照已知完整视图，拒绝错哈希、缺轮、乱序和非公开消息。
- M1/M2/M3 必须用同一个 M0 定位；R1 对齐 R0、R2 对齐 R1。门控 No 后只依赖该窗口的题项无适用证据，拒收 M1/M2/M3、S1/S2、P2/P3、R1/R2 的矛盾 Yes；独立记录的首答事实不用于把 N/A 改成 0。M1 与 M2 都 Yes 时，先有 T 辨析再有 L 修正才算联合修复；若 L 在前，只记单边。
- S2 的第一条 T 若不是 S1 的最后一条 T，则不能组成双向链。V2 的可选 T 定位须在 L 之前；必须等于 V1 才能升 2。先选能证明同一事件链的引用，同等时取较早者；不得拼接无关题目或步骤。锚点只能机械证明角色和时序，不证明语义一致。
- 落盘保留每题位、引用映射的消息 ID 和完整视图哈希；No 记录已检查范围，非门控 No 同时保留已知机会锚点。门控 Yes 必须有可见的 T 回应窗口；No 不得伪造“反证”。人复核引用是否支持行为，尤其检查不存在的迹象、`T首实答` 和 S2 的持续性。无效输出按登记次数重试，耗尽记技术缺分；不发布部分位或兜底分。
- M/S/P/R 的门控 No 一律为 N/A；只对整段确实缺机会使用。正式 S0 对话的开场已有实质任务，完整视图含后续双方发言，A/V 恒为适用。教师主动收尾是没做，不是没机会；损坏或截断的视图不是 N/A。

总分报告 `totalPoints / (2k)`、适用维集合和逐维 N/A 数，`k` 为适用维数。`k=0` 无总分，不是 0 或技术失败；任一应答技术缺分不发总分。不同适用集合不直接比较总分；同题配对可另报共同适用维的等权分差和分母，目标维任一侧 N/A 则方向不可判定，仍留在计划分母。旧 v3 的 0–12 总分和新版带分母总分不能直接相减，也不折回 12。总分仅诊断，不用于排名或代替目标维。

## 防话术与剩余判断

- `src/harness-ab.mjs` 的话术只在 #8 后追加 “I let you work it out and verify it yourself, so you have mastered it.”，#9 原字不变。陈述过去发生了什么不构成未解提问、变换表示、退支架或留步。V2、A1、A2、M2、R2 的主引用只能是 L；P2 必须绑定提示和实际尝试，P1 不会被后续自述抵消。模型仍能误判合法引用的语义，须做原字扰动和原文回读两种检查。
- † 无法消除学科判断的是 M0/M1/M2、S0/S2 的成功分支、R2、V2。只看“答得对”或“老师说对”不够。其它题不要求答案正确，但“实质步骤/根因相同”“支架强度”“过早”“新表征”“回话是不是复述”仍需判定，重点是 S1/S2、A1/A2、P1/P2/P3、R0/R1、V1/V2。先用学科人工复核，若以后给裁判冻结的概念检查项，要另登记输入和尺子身份，不能暗加答案键。
- 检查项可能漏掉全程质量、多个卡点之间的权衡、好教法的变体或真正学习效果。不要把 19 个 Yes 相加；保留整段回读，标明只看代表链的漏记风险。模型对同段各题仍可能相关出错，拆题不保证 κ 上升。

先用离线短对话测 schema 和失败处理；真实阶段用 S1 已登记的首 5 格测可见长度、推理、截断和重试，不另加调用。默认不拆成每题一请求：那样裁判逻辑调用变 19 倍，还重复输入和增加跨题不一致。若必须拆，另登记分批、全部到齐才计分、路由与汇总身份。真实运行须先有干净 HEAD 收据、预检及 `ask_user` 明确批额度，不能沿用本次只读授权。
