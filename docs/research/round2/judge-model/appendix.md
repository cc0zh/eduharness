# 附录：模型、路由和 TeachArena 收据的原文摘录

对应 [survey.md](survey.md)。公开原件均为匿名 GET；采样时间为 2026-11-21 UTC，目录和短窗口指标会变化。仓库只读，路径相对 `D:/Code/eduharness`。仅列决策相关字段，不把数据缺失补成 0。

## 1. 检索与正式接口

- OpenRouter [默认模型清单](https://openrouter.ai/api/v1/models) 476 条、[Decisions 清单](https://openrouter.ai/api/v1/models?output_modalities=decisions) 45 条、[提供方清单](https://openrouter.ai/api/v1/providers) 123 条，以 09:48:22Z 抓取为准。默认清单不是 Decisions 的全集。对 `id/name/slug` 作不分大小写匹配；查 `jev/jve/jef/jeff/jeeva/jeva`、`judge/decision/decide/decider`；另回读 Router 目录、Auto 和 Jev Router 官方文档。
- Jev 命中：默认清单是 `typesafe/jev-router`；Decisions 清单是 `typesafe/jev-1.14`、`typesafe/jev-1.13`、`~typesafe/jev-latest`；供应方是 `typesafe / TypeSafe`。近似拼写未找到另外的匹配项。未找到此处名为 Judge 的聊天模型；Judge 在原文中指用途，例如官方 [Jev vs LLM-as-a-Judge](https://openrouter.ai/blog/tutorials/jev-vs-llm-as-a-judge/)（对方任务，不是 TeachArena 的速度或质量验证）。
- [Jev 1.14 公共 HTML](https://openrouter.ai/typesafe/jev-1.14) 返回 200。自动 Markdown 读取曾返回 404，但页面 HTML、Decisions 清单和 [Jev 指南](https://openrouter.ai/docs/guides/community/jev) 一致。没有因为只查默认 GET 或 Markdown 404 判定模型不存在。
- [Jev 指南](https://openrouter.ai/docs/guides/community/jev)： “Jev does not produce reasoning traces, explanations, or free-form text. It is not a drop-in replacement for a chat model.” 固定 ID 与 latest 别名都列出。指南列两套地址 `POST /api/alpha/decisions` 与 `POST /api/v1/systemone`；本次未访问 POST。
- [Decisions](https://openrouter.ai/docs/guides/features/decisions#question-primitives)：`questions` 按键给 `noul/choice/score/box`；Noul 返回从 0.0 到 1.0 的概率及 confidence，Choice 从给定的选项中选。聊天 `response_format: json_schema` 与此不是同一机制。**推断：**选择消息号需自己定义候选、阈值和绑定。若必须产出自由文字理由，不能让 Decisions 直接产出。
- [Jev Router](https://openrouter.ai/docs/guides/routing/routers/jev-router)： “Jev makes the routing decision; the selected model generates the response.” 模型和 effort 动态；`cost_tier` 不是价格硬上限，也不是固定 effort；`allowed_models` 是偏好列表，其不可路由时可回退到不带列表。用 [router metadata](https://openrouter.ai/docs/guides/routing/routers/router-metadata) 查实际解析出的模型。[Auto Router](https://openrouter.ai/docs/guides/routing/routers/auto-router) 亦有逐请求的模型与 effort 选择。
- 09:59Z 的 `decid` 补查：默认模型清单中无这组匹配，Decisions 清单中有 Solar、Perplexity exact ID 如下。[Extractions](https://openrouter.ai/docs/guides/community/extractions)：Perplexity Decider v1.3 (Flash) 的 `locate` 能返回正文中取到的片段及 `span`；这仍不是生成解释或守 Chat Completions strict 形状。目录本次列的是 `:free` v1.3，两条付费的是 v1.2。目录价格不证明 400–500 次能稳定用免费路由。
- Mercury 付费/免费 [原页](https://openrouter.ai/inception/mercury-decide)仍可见；[付费 endpoints](https://openrouter.ai/api/v1/models/inception/mercury-decide/endpoints) 与 [免费 endpoints](https://openrouter.ai/api/v1/models/inception/mercury-decide:free/endpoints) 都返回 200 和 `endpoints: []`；两份清单均未列出它。**推断：**不作为本次可路由候选；具体停运时间和原因未读原文。裸 `openrouter/decide` 页与详情接口为 404。

## 3. strict 和推理的关键原字

- [OpenRouter Structured Outputs](https://openrouter.ai/docs/guides/features/structured-outputs)：“Support is determined per endpoint, not just per model”；“Enforcement varies by provider: some guarantee schema-conforming output, while others translate your schema into their own structured-output format or treat it as a strong hint”。其示例用 `response_format.type=json_schema`、`json_schema.strict=true`；用 `provider.require_parameters:true` 限支持候选。参见 [端点选择](https://openrouter.ai/docs/guides/routing/provider-selection#requiring-providers-to-support-all-parameters)：“Only use providers that support all parameters in your request.” 模型页 Errors：404 可表示 unknown model **or no provider can serve the request**。原代码不会将这类失败当 No 或零分。
- [OpenRouter Reasoning](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens#discovering-per-model-reasoning-options)：“For models that only support `reasoning.effort` … the `reasoning.max_tokens` value will be used to determine the effort level.” `supports_max_tokens` 明列 true 才是预算能力声明；缺字段不要声称硬上限。文档说 `exclude` omit tokens from **response**；它不是禁用。Anthropic [原生手动预算](https://platform.claude.com/docs/en/build-with-claude/extended-thinking)在 Claude 4.7 及后续不接受旧 `budget_tokens`。实际消费必须和同次出站、路由对账。
- [Qwen3 235B](https://huggingface.co/Qwen/Qwen3-235B-A22B-Instruct-2507)：“This model supports only non-thinking mode and does not generate `<think></think>` blocks in its output.” [Qwen3-Next](https://huggingface.co/Qwen/Qwen3-Next-80B-A3B-Instruct)：“supports only instruct (non-thinking) mode and does not generate `<think></think>` blocks in its output.” [Parasail](https://docs.parasail.io/parasail-docs/guides/structured-output)：“Combine `strict: true` with `additionalProperties: false` for the tightest output.” DeepInfra 的 [API 模型页](https://deepinfra.com/Qwen/Qwen3-Next-80B-A3B-Instruct/api)已读；对这份具体 schema 的原生接受实证未读原文。以 OR 端点字段为支持依据，不当作样本合规证明。
- [Mistral Reasoning](https://docs.mistral.ai/inference/conversations/reasoning) 对 Small 4 的 `none`：“The model thinks minimally and the thinking chunk is omitted from the response.” 不是实报 0 的证据。[Mistral Custom Structured Outputs](https://docs.mistral.ai/inference/conversations/structured-output/custom)说明可提交 JSON Schema。
- [Gemini thinking](https://ai.google.dev/gemini-api/docs/thinking)的表把 `gemini-2.5-flash-lite` 列为 Off，把 3.8 Flash 列为 On (medium) 和 low/medium/high。 [Flash-Lite 原卡](https://aistudio.google.com/docs/models/gemini-2.5-flash-lite)：“we are limiting access to the 2.5 models to users who have actively used them in the past”；没有说 OpenRouter 上新应用必然被拒。 [Gemini structured output](https://ai.google.dev/gemini-api/docs/structured-output#limitations) 提醒大型/深嵌套 schema 可被拒，`enum` 和 `anyOf` 分支扩大 grammar。固定路由的实际 enforce 仍待测。
- [Claude reasoning](https://platform.claude.com/docs/en/build-with-claude/thinking#turning-thinking-off)：“Claude Haiku 5.5 … accepts `thinking: {type: "disabled"}` at … `high` or below.” [Haiku 原卡](https://platform.claude.com/docs/en/models/haiku-5-5/overview)：“Omit `temperature`, `top_p`, and `top_k`.” [Claude schema 限制](https://platform.claude.com/docs/en/build-with-claude/structured-outputs#schema-complexity-limits)：“Parameters with union types” 最大 16，包含 `anyOf` 或 type array。复杂 grammar 可报 400，编译超时 180 秒。TeachArena 19 题有 37 个必填 nullable `anyOf(integer enum, null)` 槽。**推断：**原样转译到 Anthropic 原生 strict 会超限；不能假设 OR 会替应用改写并本地复核。没实跑，不说 OR 已拒。
- [服务档](https://openrouter.ai/docs/guides/features/service-tiers)及[提供方 slug](https://openrouter.ai/docs/guides/routing/provider-selection#provider-slugs)：裸 slug 可匹配多变体；变体/地区/tier 必须核对真实路由。冻结试验用准确端点与标准档，另关 fallback。 `preferred_max_latency` 只影响优先级；不要把它当 180 秒硬截止。
- [API 错误](https://openrouter.ai/docs/api_reference/errors-and-debugging)：已开始生成时，返回的 HTTP 状态可仍是成功，错误由正文/SSE data 事件携带。 `src/models.mjs` 的收据只有在可见正文、正常结束和完整本地校验都满足时，才是可用于算分的判决。
