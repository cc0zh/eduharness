# 阶段 1 收口：v3 带边界采用

**用户决定走路线 A。** `e1-binary-v3` 是阶段 2b 和阶段 3 的工作评分器，带边界采用。v3、v4 均未通过冻结门禁，不冻结、不改判线、不补试。监工意见仅供参考，路线取舍由用户决定。工作评分器不能单独用于排名或宣称后续 A/B 通过。

## 三条已知边界

1. **A1 可能把跟算当成自主推理。** `A1-only-proposes` 中，教师已展开式子后，学生 #9 继续跟算。v3 两遍都判 A1=Yes，特异度为 1/2。从 `A1-only-proposes:judge:4:3:1` 和 `A1-only-proposes-r2:judge:4:3:1` 回读，不把两遍一致当作正确。
2. **V1 对事后话术敏感。** `V2-normal-claim` 的 #6 宣称学生已独立解释，`V1-claim-none` 的 #8 否认真问句。v3 两格都漏掉 #4，不能用一条事后话术推翻原问句的人工回读。调用分别为 `V2-normal-claim:judge:4:6:1` 和 `V1-claim-none:judge:4:6:1`。
3. **同一输入的单次判定会翻转。** 同版本、同对话、同一维的保存请求一致时，仍观察到布尔题和分档翻转。下表只描述这批重复，不给新样本的误差界，也不把未观察到翻转的题当成无噪声。

**A2 覆盖边界。** v3 冻结复测中 A2 召回为 1/2，失败格 `A2-still-chosen` 后来按修订口径改判为 No，并已退役；按修订口径，v3 只实测过一个 A2 正例 `A2-choose-identity-test`，未测 A2 的事后否认格。历史冻结结果不回改，样本差别见[同输入回归归因](round2-binary-v4-regression-attribution.md#口径与原件)。

## 同输入翻转率

原件为 [①h Gemini 代理补跑](../runs/round2-bakeoff-gemini-proxy-01/manifest.json) 18 格、[v3 冻结复测](../runs/round2-binary-v3-freeze-gemini-01/manifest.json) 51 格、[v4 冻结复测](../runs/round2-binary-v4-freeze-gemini-01/manifest.json) 60 格。计算读取并验真各批 `journal`、对话哈希、判决绑定及其指向的成功调用原件。不用报告总分倒推题位，不纳入失败首试，不把内容相同但多份落盘副本算成重复。

同版本内按对话文件 SHA256、维度以及保存的请求内容分组。请求内容包含系统提示（含重试提示）、用户 JSON 字符串、保存的出站字段和代理标记；不含本地时间戳、run/格/调用坐标。组内每两个判决计一对，跨 v3 两批也可配对；v4 单列，不混算。翻转指 Yes/No 不同，引用变化不单独计翻转。每个指标的分母少于 3 对时标「证据不足」；缺判不是 No。

## v4 退步

[同输入回归归因](round2-binary-v4-regression-attribution.md)对齐 50 格。v4 的 S1 验证或迁移目标从 3/3 降到 1/3，原因是第 2、3 遍 `normal` 丢 V1 #4；四个 `normal` 变体的验证分档从 `1/2/1/0` 变为 `0/0/1/0`。v4 修正了两遍 A1 跟算例，九格旁证目标位均命中，但两处事后话术漏判未修复。S1 其他方向和旁证不能替代失败的门禁，现有原件不能把回归归到某一句提示。v3 自己也未达到定向 V1/A1/A2 和 `normal` 四格判线，见 [v3 冻结复测](../runs/round2-binary-v3-freeze-gemini-01/freeze-retest-report.md)。
