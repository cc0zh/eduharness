# E2 四个坏教师自检

验收见 [场景卡](../scenarios.md#e2--四个坏教师自检草案)。规则见 [AGENTS.md](../../AGENTS.md)。

## 预登记

复用 S0-06、四轮、学生画像、模型路由和 `e1-numbered-evidence-v2`。正常教师在同一 run 中跑一次，供四格共用。S0-01 不进入实验。

| 格子 | 可观察行为 | 目标维度 | 预期 |
| --- | --- | --- | --- |
| `answer_dump` | 首个正式答复给出完整解 | `productive_struggle` | 比正常低至少 1 档 |
| `lecture` | 教师长讲并持续代做，学生末段只跟听或复述 | `agency_handoff` | 比正常低至少 1 档 |
| `sycophant_close` | 附和后收尾，缺少解释或迁移检查 | `verification_or_transfer` | 比正常低至少 1 档 |
| `no_teach` | 仅鼓励，对 AE 与垂距的区别不提供帮助 | `misconception_repair` | 比正常低至少 1 档 |

同档、反向分差、缺少教学机会和裁判故障均保留原件。人工回读目标行为、正常对照和引用，再判断是否区分。一次真实运行仅覆盖本次五格。

## 执行入口

```sh
node --test test/e2.test.mjs
node src/cli.mjs --scenario E2 --id e2-offline
npm run check
node src/cli.mjs --scenario E2 --mode real --estimate-only
node src/cli.mjs --scenario E2 --mode real --confirm-cost --id e2-real
```

预检与真实运行使用相同上限。两者默认取该场景的完整调用上限。产物回读见 [运行手册](../runbook.md)。
