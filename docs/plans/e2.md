# E2 四个坏教师自检

阶段归属与完成条件见 [S1 的 E2 子卡](../scenarios.md#e2-四个坏教师自检)。规则见 [AGENTS.md](../../AGENTS.md)。

## 预登记

复用 S0-06、四轮、学生画像、模型路由和 `e1-numbered-evidence-v2`。正常教师在同一 run 中跑一次，供四格共用。S0-01 不进入实验。

目标行为、维度、分档条件及已知问题统一见[裁判契约](../../contracts/judge/README.md#e2-坏教师的目标维度)。一次真实运行仅覆盖本次五格。

## 执行入口

```sh
node --test test/e2.test.mjs
node src/cli.mjs --scenario E2 --id e2-offline-YYYYMMDD-01
npm run check
node src/cli.mjs --scenario E2 --mode real --estimate-only
node src/cli.mjs --scenario E2 --mode real --confirm-cost --id e2-real-YYYYMMDD-01
```

真实执行前按[运行手册](../runbook.md)检查收据、预估和取得授权。将日期和序号换为未用过的值。
