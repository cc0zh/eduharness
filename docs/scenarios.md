# 场景卡

方法见用户级技能 `evidence-first-project-workflow`。

## E1 · S0-06 两格

| 栏 | 内容 |
| --- | --- |
| 谁 | 只先读 README 和 AGENTS.md 的新接手者。 |
| 条件 | 新仓库，与旧数据一致。pi 版本锁定。离线默认；真实模式须有费用授权和环境变量凭据。 |
| 能完成什么 | 一条命令分别运行正常教师与 `answer_dump`，两种模式共用主路径。 |
| 证据 | 退出 0；一个 run 有 manifest、逐轮记录、遥测、裁判原件及结果；两格都有有效总分，每个引用都能回读，`answer_dump` 的直接给答案维度至少低 1 个原始分档；`npm test` 和 `npm run check` 通过。 |
| 失败可定位 | 核心错误子类、格子、角色、轮次、调用及原件。 |
| 不算交付 | 仅离线、兜底造分、内部标记泄漏、反向契约依赖、排名式表述。 |

## E2 · 四个坏教师自检（草案）

S0-06 的预登记、命令和证据入口见 [E2 计划](plans/e2.md)。

| 栏 | 内容 |
| --- | --- |
| 谁 | 维护尺子、准备变更裁判契约的人。 |
| 条件 | 固定题目、学生、评测身份和正常对照；为每个坏教师预登记该题可观察的行为及维度。 |
| 能完成什么 | 分别验证：`answer_dump` 提前给答案、`lecture` 不交还解题步骤、`sycophant_close` 不验证即附和结课、`no_teach` 未提供目标概念的帮助。 |
| 证据 | 每种行为单独记录原件、维度、预期和实际分档及绑定消息 ID；正常对照使用同一维度。 |
| 失败可定位 | 标明格子、维度、证据分组和消息 ID；分清缺少教学机会、尺子未识别、裁判故障。 |
| 不算交付 | 只报总分、用非目标维度替代，或把模拟结果当真实尺度灵敏度。 |

## E3 · S0-01 答案键（草案）

| 栏 | 内容 |
| --- | --- |
| 谁 | 数据维护者或复核历史对话的人。 |
| 条件 | 锁定原题、历史确认原件和独立推导；原题、变式和私测必须区分。 |
| 能完成什么 | 找出教师确认 57 与原题答案 43 的冲突，同时对确认 43 的样本不报冲突。 |
| 证据 | `contracts/dataset/contract.test.mjs` 的失败与通过输出，答案推导和原件确认 ID `m10`。 |
| 失败可定位 | 给出题号、原题或变式、作答值、确认消息 ID 和答案键版本。 |
| 不算交付 | 静默修改旧数据、混用私测答案键，或只引用报告不校验原件。 |

## E4 · 预算截断（草案）

| 栏 | 内容 |
| --- | --- |
| 谁 | 模型运行和遥测维护者。 |
| 条件 | 固定 provider 响应夹具，包含可见截断、推理耗尽导致的空正文、用量不明的空正文和本地 deadline。 |
| 能完成什么 | 区分故障分类、复核调用级重试上限，并在超额前拒发请求。 |
| 证据 | 保存每次请求上限、停止原因、推理用量或未知标记、耗时、部分原件和预算拦截测试。 |
| 失败可定位 | 格子、角色、轮次、调用、尝试、输出上限和本地或供应商中断原因。 |
| 不算交付 | 把缺失用量当 0，或给截断正文打分。 |

## E5 · 改进对照（草案）

| 栏 | 内容 |
| --- | --- |
| 谁 | 提交 harness 改动、需要判断行为变化的人。 |
| 条件 | 预登记改动和预期维度；两侧固定题目、学生、教师模型、尺子和运行预算，仅变更 harness。 |
| 能完成什么 | 对预登记维度给出改好、改坏或无变化的判断，并指出对应对话行为。 |
| 证据 | 两侧 manifest、有效总分、目标维度分档及各自可回读的消息 ID；记录无法判定的格子。 |
| 失败可定位 | 指向身份差异、缺失证据、指定维度或对话段；基础设施故障单列。 |
| 不算交付 | 更换尺子后直接比较、只报平均分或给教师排位。 |
