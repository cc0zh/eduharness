# 验收场景卡

TeachArena 是一个评测项目，用一把专门用于改进教学 Agent harness 的尺子，判断一次 harness 改动让教学行为变好、变坏还是没变，并指出是哪段对话、哪个行为。

题量只有 15 道训练题和 25 道测试题。TeachArena 不用于排名，也不是 benchmark。

按以下四步验收，以证据判断是否完成。方法见用户级技能 `evidence-first-project-workflow`，进度见[当前状态](status.md)，评分口径见[裁判契约](../contracts/judge/README.md)。

1. **尺子能分辨坏教师。** 已完成。`0302396` 记录了 [S1 用户签收](archive/status-log-2026-11.md#s1-场景卡逐栏)，原预登记的三次完整稳定性重复未达成。
2. **尺子和人的判断一致。** 预登记计划采用单人盲标和先锁标签、后揭分的顺序。后来锁定 15 条训练对话，实际标签来自 AI 预标与用户逐格复核。逐维结果衡量经用户认可的跨模型一致性。见[训练初评和复评](archive/status-log-2026-11.md#补尺子训练初评和复评)。
3. **尺子在没见过的题上依然有效。** 见[第 3 步未见题验证](#第-3-步-未见题验证)和[当前状态](status.md)。
4. **尺子能测出真实的 harness 改动，且不被讨好裁判的改动骗过。** 三侧真实对照已执行，本次改进未达采用线。话术未触发欺骗判据。行为证据来自 AI 回读。[运行记录](archive/status-log-2026-11.md#第-4-步-harness-对照)

第二轮 ① 另用候选二元尺子复判首轮 S1 冻结五格。该结果只验证固定对照，不改写首轮验收记录。[第二轮 ① 状态](archive/status-log-2026-11.md#round2-s1)

## 人工盲标协议

通过线和证据核验要求以[补尺子计划](research/ruler-expand/plan.md)第 4 节的预登记为准。训练有效配对率的计划分母是锁定的 15 条对话，不沿用该节原方案的样本数示例。逐维报告有效分母、标签档位覆盖和缺分，并按预登记回读评分证据。κ 未定义或任何预登记通过线未达时，训练一致性记为未通过。冻结另见[冻结记录](archive/status-log-2026-11.md#冻结记录)，不因冻结改写统计结论。

| --- | --- |
| 谁 | 要验证尺子在留出题上能否分辨坏教师的用户。 |
| 条件 | [冻结尺子](archive/status-log-2026-11.md#冻结记录)和锁定的 25 题通过机械准入；训练初评与测试身份分开。按 `plan.md` 第 5 节的最省档和通过线执行。 |
| 能完成什么 | 每题比较 `normal` 与一项指定的坏教师条件。逐组报告总分方向和目标维度命中，逐维报告分布、跨题方差与区间。四组都达到预登记目标维度的判线才通过。 |
| 证据 | 测试 run 的 `test-report.md`、逐题计算结果、绑定引用、启动和进程收据、请求日志以及 `--verify-run` 输出。见[运行手册](runbook.md)。 |

| 不算交付 | 只跑离线、改尺子或通过线、把故障题从计划分母悄悄删去，或用单次结果证明跨次稳定。 |

## 第 4 步 手写 harness 变体 A/B

状态：已在冻结 v3 上执行一次诊断对照，候选未达采用线。第 3 步的已知限制仍适用。三侧运行、同题计分和 AI 行为回读见第 4 步报告（`runs/harness-ab-v1/ab-report.md`）。

| 栏 | 内容 |
| --- | --- |
| 谁 | 手写 harness 变体的操作者与独立判断教学行为的人。 |
| 条件 | 使用第 3 步已验证的冻结尺子。人工手写 2–3 个变体，至少包括「确实更好」和「只讨好裁判」两类。预登记题目、各变体的改动、目标维度和预期行为。基线与候选使用同一批题和学生条件，各自独占 run 根目录。除预登记的 harness 改动外，其他评测条件一致。[身份核对](../contracts/artifacts/README.md#评测身份) |
| 能完成什么 | 做一次 A/B，将各候选分别与同一基线对照，再核对人的判断。尺子应识别人工确认的真改进，不应把人工确认的只讨好裁判判为改进。逐项说明变好、变坏、没变或不可判定，并指出具体对话和行为。 |
| 证据 | 在 `runs/<ab-id>/ab-report.md` 记录预登记哈希、各侧根目录与 ID、启动和进程收据、请求日志、复核退出码、评测身份、逐题分差和消息序号。先回读同题对话的行为及原文，再看分数。由 AI 回读时明确标注，不写作人工复核。 |
| 失败可定位 | 指明候选、题目、目标维度和消息 ID，区分身份漂移、运行故障、机会或证据不足、漏判真改进，以及把讨好裁判误判为改进。 |
| 不算交付 | 只报总分或排名、缺一类变体、两侧共用 run 根目录、改动尺子、没有人工对照，或把不可判定当作没变。一次 A/B 只验证本批次的对照，不证明跨次稳定性。 |
