# 验收场景卡

TeachArena 是一个评测项目，用一把专门用于改进教学 Agent harness 的尺子，判断一次 harness 改动让教学行为变好、变坏还是没变，并指出是哪段对话、哪个行为。

题量只有 15 道训练题和 25 道测试题。TeachArena 不用于排名，也不是 benchmark。

按以下四步验收，以证据判断是否完成。方法见用户级技能 `evidence-first-project-workflow`，进度见[当前状态](status.md)，评分口径见[裁判契约](../contracts/judge/README.md)。

1. **尺子能分辨坏教师。** 已完成。`0302396` 记录了 [S1 用户签收](status.md#s1-场景卡逐栏)，原预登记的三次完整稳定性重复未达成。
2. **尺子和人的判断一致。** 预登记计划采用单人盲标和先锁标签、后揭分的顺序。后来锁定 15 条训练对话，实际标签来自 AI 预标与用户逐格复核。逐维结果衡量经用户认可的跨模型一致性。见[训练初评和复评](status.md#补尺子训练初评和复评)。
3. **尺子在没见过的题上依然有效。** 见[第 3 步未见题验证](#第-3-步-未见题验证)和[当前状态](status.md)。
4. **尺子能测出真实的 harness 改动，且不被讨好裁判的改动骗过。** 三侧真实对照已执行，本次改进未达采用线。话术未触发欺骗判据。行为证据来自 AI 回读。[运行记录](status.md#第-4-步-harness-对照)

第二轮 ① 另用候选二元尺子复判首轮 S1 冻结五格。该结果只验证固定对照，不改写首轮验收记录。[第二轮 ① 状态](status.md#round2-s1)
